# 1. ⚠️ 시작 전 반드시 알아야 할 지뢰 4개

실제 환경에서 **직접 확인한 것들**입니다. 모르고 시작하면 시간을 크게 날립니다.

### 지뢰 ① `'SEOUL'` 을 넣으면 INSERT는 되고 조회가 전부 500 🔴

`PLAN/조별실습_plan.md` 에 있는 시드 SQL은 `category='SEOUL'` 을 씁니다. **그거 쓰지 마세요.**

- DB 컬럼은 `VARCHAR(50)` 이라 **INSERT는 성공**합니다
- 그런데 JPA가 읽을 때 `@Enumerated(EnumType.STRING) Category` 로 변환하다 **터집니다**
- `GlobalExceptionHandler` 가 원인을 삼켜서 **로그도 안 남습니다**
- 증상: `{"success":false,"message":"서버 오류가 발생했습니다"}` 만 계속 나옴

**→ 쓸 수 있는 값은 이 4개뿐입니다.**

| enum 값 | 우리 의미 |
|---|---|
| `SECURITY` | **서울** |
| `MOBILE` | **경기** |
| `DATABASE` | **인천** |
| `OTHER` | 기타 |

> 왜 `SEOUL` 을 못 만드나? → `Course.Category` enum에 값을 추가하면
> **4번의 recommend-service(Pydantic)가 즉시 ValidationError로 500** 이 됩니다.
> 게다가 그쪽은 `httpx.HTTPError` 만 catch해서 **안 잡힙니다.** 기존 값 재해석이 유일한 답입니다.

---

### 지뢰 ② 게이트웨이(8080)는 토큰 없으면 401 🔴

```
curl localhost:8080/api/courses  →  401 Unauthorized   ❌
curl localhost:8082/api/courses  →  200 {"data":[]}    ✅
```

**→ 내 작업·시드·검증은 전부 `8082` 직통으로 합니다.** 8080은 1번(프론트)의 영역입니다.
게이트웨이는 **소스가 없는 prebuilt 이미지**라서 라우팅을 못 바꿉니다. 뚫으려고 시도하지 마세요.

---

### 지뢰 ③ 공급사 users 3~6번이 DB에 없습니다 🔴

```
현재 users = id 1(홍길동/STUDENT), id 2(김강사/INSTRUCTOR)   ← 2건뿐
courses.instructor_id → FOREIGN KEY users(id)
```

**→ users를 먼저 안 만들면 공고 INSERT가 FK 오류로 전부 실패합니다.**
이게 진짜 첫 번째 단계입니다.

---

### 지뢰 ④ `price` 는 `DECIMAL(10,2)` — 최대 약 1억

6억 8천을 원 단위로 넣으면 **오버플로**.
**→ 분양가는 "만원" 단위로 저장합니다.** `68000` = 6억 8,000만원.

---

### ✅ 좋은 소식: 컨테이너에서 공공 API 인터넷이 뚫려 있습니다

```
docker exec lecture-course wget https://api.odcloud.kr/...  →  HTTP 401
```
401 = **네트워크 도달 O, 인증키만 없음**. 사내망 차단 위험은 없습니다.

**완료 조건**

> ⚠️ 키가 2종류입니다. **Encoding 키 = 주소창에 직접 붙일 때 / Decoding 키 = curl·WebClient·코드에서 쓸 때.**

### B-1. 키/네트워크 문제 — **손실 거의 0**
`PLAN/공공API_연동가이드.md` 5장의 필드 매핑표로 **두 기관의 실제 응답 구조를 그대로 흉내 낸 JSON 파일 2개**를 만들고 `mode: cache` 로 시작합니다.

```
resources/mock/cheongyak.json → {"currentCount":10,"data":[{"HOUSE_NM":...,"PBLANC_NO":...}]}
resources/mock/lh.json        → [{"dsSch":[...]},{"resHeader":[{"SS_CODE":"Y"}],"dsList":[{"PAN_ID":...}]}]
```

**핵심: 파일 구조를 실제 응답 구조와 똑같이 만듭니다.** 그러면 클라이언트·어댑터 코드가 **전부 그대로**이고, 키가 나오면 `mode: live` 한 줄만 바꾸면 됩니다.

> 발표 멘트: *"두 기관은 응답 구조가 근본적으로 다릅니다. 청약홈은 `{data:[...]}`, LH는 `[{dsSch},{resHeader,dsList}]` 2원소 배열입니다. 이 차이를 어댑터가 흡수하고, 그 뒤 코드는 두 기관을 구분하지 않습니다."*

**→ 평가받는 건 "어댑터 패턴으로 이종 시스템을 통합했다"는 설계지, "인증키를 받았다"가 아닙니다.**
