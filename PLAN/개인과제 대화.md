## 오늘 배운 핵심 개념 (대화 중 질문했던 것들)

- **MSA vs 모놀리식**: 서비스 격리로 장애가 전체로 퍼지지 않음
- **Docker**: 컨테이너(실행) / 이미지(패키지) / Dockerfile(레시피) 구분
- **docker-compose**: 여러 컨테이너를 순서대로 한 번에 켜는 도구
- **포트**: 3306(MariaDB 내부) vs 3379(외부 접근용) — Docker가 중간 연결
- **API**: 두 프로그램이 대화하는 창구. API 키는 그 창구 허가증
- **Swagger UI**: 프론트 없이 백엔드 API 직접 테스트하는 도구
- **OSI 7계층**: 네트워크(3층 IP/DNAT) vs 애플리케이션(7층 Eureka/Gateway)
- **Eureka**: 서비스 이름 → IP 주소 찾아주는 전화번호부
- **Kafka**: 서비스 간 비동기 메시지 전달 (결제완료 → 청약상태 자동변경)
- **ERD vs API 명세서**: ERD는 DB 구조(창고), API 명세서는 주문 방법
